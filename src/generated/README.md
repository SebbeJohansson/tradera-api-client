# Generated sources

Everything below this directory is generated. Do not edit these files directly.

- `rest/schema.ts` is generated from `openapi/tradera-v4.json` by `openapi-typescript`.
- `rest/client.ts` is generated from the same contract plus `openapi/client-operations.json`.

The generator itself is authored TypeScript at `scripts/generate-client.ts`.

Regenerate this directory with:

```bash
yarn generate
```
